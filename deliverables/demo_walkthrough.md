# Working Demo Walkthrough (about 6 minutes)

Stop any running copy of the app, then start with a clean sample student. This deletes data saved in the app.

```bash
cd code
python run.py --reset
```

| # | Do this | What to point out |
|---|---|---|
| 1 | Open **Home** | Animated readiness calculated from real parts. The data notice says postings are synthetic |
| 2 | Open **Resume Review**, clear **Company**, and press **Review my resume** | Intake asks for the missing detail first |
| 3 | Pick *Demo Company 03: Backend Developer* and review | Fixed 100-point score, reasons, gaps and confidence |
| 4 | In **What-if simulator**, select Docker and a formatting fix | The estimated score and changed rubric parts update immediately |
| 5 | Press **Reject** on the Docker advice, save a reason, and review again | Only the Docker advice is hidden. This is feedback memory |
| 6 | Open **Interview Coach**, create questions, start the timer, and type or speak | Content feedback plus words, fillers and spoken pace |
| 7 | Open **Career Compass** | Ranked skill roadmap with sources. Track a best-fit job in one click |
| 8 | Open **Market Trends**, then a **Posting #** source | Research steps and the source behind each claim |
| 9 | Open **Weekly Report**, press **Generate new report** | Mission Control shows the real agents working, then the report, evidence and QA appear |

Voice input needs a browser with speech recognition, such as Chrome or Edge, and microphone permission. Screenshots are in the `screenshots` folder.
